常见问题

首次打开被系统拦截怎么办？

言墨是个人开源项目，应用为 ad-hoc 签名、未经 Apple 公证。确认来源后，在终端执行：

xattr -dr com.apple.quarantine /Applications/言墨.app

或先打开一次，再到「系统设置 → 隐私与安全性」底部点「仍要打开」。

首次使用需要配置什么？

在「设置 → 本地模型」准备语音识别模型，默认从 ModelScope 下载并复用已有缓存。在「设置 → API 服务」填写并启用一个 OpenAI 兼容文字接口，包括服务地址、模型 ID 和服务要求的 API Key。按提示允许麦克风和辅助功能权限。

需要联网吗？会上传录音吗？

首次下载语音模型和访问远程文字 API 需要联网。默认语音识别在 Mac 上运行。只有主动启用在线语音识别时，才会把音频发给所配置的语音服务。

对电脑有什么要求？

需要 Apple Silicon（M 系列芯片）及 macOS 14 或更高版本。语音模型首次单独下载。

支持 Windows 吗？

Windows 版正在开发中，暂不能使用。

收费吗？

言墨免费，采用 MIT 开源协议。API 费用由你选择的服务商决定。
