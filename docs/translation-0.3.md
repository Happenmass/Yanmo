# 言墨 0.3 · 本地翻译

原型记录：2026-10-21；当前流程见[双路识别与正文生成](asr-fusion.md)。Apple Silicon / macOS；ASR 保持 Qwen3-ASR-1.7B-8bit，翻译复用 Qwen3-4B-Instruct-2507-4bit。未下载新模型。

## 功能与边界

| 入口 | 默认快捷键 | 流程 |
| --- | --- | --- |
| 语音输入 | 保留已有配置 | 录音 → ASR → 正文生成 → 写入时当前焦点 |
| 口述翻译 | Control＋Option＋T | 录音 → ASR → 翻译 → 写入时当前焦点 |
| 划词翻译 | Control＋Option＋S | 显式选区 → 同一翻译能力 → 独立弹窗 |

两种翻译目标分别保存，默认英语。可选英语、简体中文、日语、德语。设置支持每个入口绑定多组快捷键，包括 Fn、左右修饰键与普通组合键；跨入口重复键会被拒绝。新版本迁移保留原快捷键，新默认键若与原配置冲突则不添加。

口述翻译在录音开始时固定目标语言。整理开关不影响翻译；翻译失败保留识别原文，不自动写入原文。译文向写入时的当前焦点粘贴一次，允许途中切换应用和输入位置。

划词优先读 AXSelectedText，其次用明确选区截取 AXValue。应用未提供时尝试 Cmd+C，只接受本次产生的内容并恢复旧剪贴板；已知空选区直接提示。密码框、空内容、超过 4000 字的内容拒绝处理。没有图片 OCR，也不读取全屏文字。当前应用切换时终止复制回退。

弹窗仅在内存中保留原文与译文，关闭清除；可切换语言、重试、取消或复制，不自动替换原文。弹窗使用宣纸、宋体标题、墨色正文与朱砂按钮，沿用现有视觉；没有声音或装饰动画。

## 自动与模型验证

- `swift run YanmoChecks`：8 项通过，含四个语言值、快捷键持久化与跨功能冲突、纯修饰键释放和组合键抑制的回归。
- `python3 -m unittest discover -s engine -v`：8 项通过，含独立翻译调用、目标语言白名单、空输入、长度边界。
- 原生 Debug / Release 构建通过，应用 ad-hoc 签名严格校验与构建脚本语法检查通过；当前运行的是含验证菜单的 Debug 包。
- 真实本地模型完成 8 条合成输入，覆盖四种目标、已为目标语言、混合语言、文本中包含指令、金额和否定。完整输出见 [基准记录](translation-benchmark-2026-10-21.json)，脚本为 `scripts/benchmark-translation.py`。
- 首条冷加载 4.113 秒；后续短句 0.356～0.590 秒，不含录音、ASR 或粘贴耗时。该组是有限样本检查，不是通用翻译质量评分。
- 样本金额、交付日与否定保留；德语输出有冠词错误（Der Budget 应为 Das Budget）。数字写法按目标语言的自然表达处理。

## 原生界面验证

- 设置页显示三个入口与两个独立目标选择器；原有 Fn、左 Control 配置保留。
- 为划词入口录制已用于口述翻译的 Control＋Option＋T，界面拒绝冲突，取消录制后原配置仍在。
- 文本编辑选择合成句「预算是3500元，周五交付，不是周四。」后，通过 Debug 验证命令走真实选区读取 → 本地翻译 → 独立弹窗。
- 弹窗显示英语译文；切换日语、德语后重新翻译，原文档不变。复制德语译文并在新的文本编辑文稿粘贴，内容一致。
- 没有选区时弹窗提示先选中文字；未读取先前的德语剪贴板，复制与重试按钮禁用。
- 「验证翻译写入」将合成中文译为英语，文本编辑正文实际出现译文，并返回自检通过。该命令跳过 ASR，用于验证翻译与写入连接。
- 更新构建后，通过系统界面重新登记同一应用的辅助功能，Fn 和左 Control 显示已启用；未修改权限数据库。

实体全局快捷键与麦克风的完整新模式仍需用户验收。电脑操作工具不可靠地触发 Carbon 全局组合键，且不能直接操作当前 ChatGPT 对话框；不能把 Debug 入口的检查等同于这两项验收。
