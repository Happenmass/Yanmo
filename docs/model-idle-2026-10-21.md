# 模型空闲卸载验证（2026-10-21）

连续空闲 3600 秒后，应用在推理串行队列退出工作进程，释放 ASR、LLM 与 Metal/分配器缓存。磁盘权重保留。录音、处理和写入阶段暂停空闲计时，结束或取消后重新计时。请求完成后也会重置计时；卸载与推理不并发。
