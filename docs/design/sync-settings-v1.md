## 界面结构与交互规则

1. **视觉与排版**
   - 沿用宣纸底 `#f6f3ec`、玄青墨色、`2px` 以内极小圆角与去卡片化细线分割，无阴影、无气泡卡片。
   - 左侧导航栏选中「设置」并带朱砂短竖笔；顶部保留 `AcpmRuntime 服务` 的状态衔接，其下为宋体标题「跨端同步」。
2. **空间状态与主操作**
   - 未开启时提供朱文印主按钮「开启跨端同步」与次按钮「加入已有空间 / 恢复码恢复」。
   - 已开启时显示石青方点「跨端同步 · 已开启（端到端加密）」与截断空间标识（如 `空间 xj7s…i3pm`），右侧提供朱文印主按钮「立即同步」与细下划线次按钮「查看恢复码」。
3. **添加设备与大附件策略**
   - 左侧提供「生成配对二维码」（默认同时授予 `inference` 与 `yanmo.sync`，可扩展选择「仅推理共享」）与「扫码或粘贴加入已有空间」入口。
   - 右侧仅在生成配对会话后显示宣纸底一次性二维码预览，下方标明「3 分钟内有效 · 不含空间根密钥」。
   - 下方提供独立开关「自动缓存跨端录音与截屏附件（关闭时仅在播放或查看时按需拉取）」，默认关闭以节省移动与局域网流量。
4. **已绑定中转节点（Hub）与已配对设备**
   - 中转节点按行显示名称、mDNS 主机/局域网地址、发现/同步状态及「立即同步」或「编辑地址」（用于补充 Tailscale / HTTPS 远程地址）。
   - 已配对设备按行显示设备名、平台、`推理` / `同步` 权限标签、最近活跃时间及「移除」（吊销设备）；仅授权推理的共享设备以淡赭石虚线标签 `仅推理` 明确区分数据隔离。
