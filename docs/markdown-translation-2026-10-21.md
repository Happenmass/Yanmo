# Markdown 翻译与原生渲染

2026-10-21。本次使用合成技术文档测试，不包含用户选区或口述内容。

## 行为

- Foundation Markdown 解析，SwiftUI 原生渲染；无 WebView、脚本、外部渲染包或网络资源。
- 支持标题、粗体/斜体、嵌套有序/无序列表、引用、分隔线、表格、链接、行内代码与围栏代码块。代码采用轻量本地词法着色，宽代码与表格可横向滚动。
- 译文默认排版，原文可展开；可切换 Markdown 源码。复制译文保留标记，代码块可单独复制。
- 翻译提示词要求保留结构、链接地址与代码，不添加外层包装、解释或 HTML/CSS。与普通转写整理的输出清理分离，不剥掉译文代码围栏或代码中的 `<think>` 字面量。
- 围栏代码和行内代码先替换为唯一标记，校验数量与顺序后还原。缺失、重复或重排时报错，保留原文。纯代码直接返回，无需模型。

## 验证

- `swift run YanmoChecks`：10 项通过，包含结构解析、表格对齐、嵌套列表和代码原文检查。
- `python3 -m unittest discover -s engine -v`：14 项通过，包含 Markdown 清理、代码保护、标记错误拒绝和纯代码免推理。
- 原生应用构建及 ad-hoc 签名通过。
- `scripts/benchmark-markdown.py` 用当前 Qwen3-4B-Instruct-2507-4bit 跑 3 例：英→简中技术文档、中→英含 JSON 文档、纯代码。结构/代码检查全部通过，结果在同名 JSON。耗时 4.521 秒（含首次加载）、1.118 秒、纯代码约 0 秒；不是通用性能承诺。
- 首次仅修改提示词时，真实模型仍翻译了代码注释与 JSON 字符串，因此加入程序级保护，没有依赖提示词保证代码完整性。
- 实际应用调试入口读取文本编辑中的合成 Markdown，完成真实本地翻译；弹窗目视检查标题、粗体、嵌套列表、引用、代码着色、表格与链接通过。排版/源码切换通过；复制译文后检查剪贴板，围栏、注释、字符串、链接地址与表格标记保留。
- 本次通过调试入口验证选区到弹窗路径，没有重新验证实体 Control＋空格。

## 边界

- 前台选区优先读取自动复制提供的 HTML，并转换语义结构；无 HTML 时回退纯文本。页面字号、CSS 配色和复杂合并单元格不保证复现。
- 不运行 HTML、代码、Mermaid，也不渲染远程图片。代码着色是轻量规则，并非完整语言语法服务。
- 程序级保护覆盖围栏和反引号行内代码；缩进代码等其他 Markdown 形式仍依赖模型保留。
- 三个合成例证明这组结构可保留，不代表所有文档的翻译质量已完成评估。
